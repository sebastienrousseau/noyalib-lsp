# noyalib-lsp 0.0.55

Hand-written Highlights for the GitHub release page; the rest of the page
(What's Changed, Checksums, Full Changelog) is generated at release time.

## Highlights ⭐️

* **A malformed frame no longer stops the server**: huge `Content-Length` values, non-UTF-8 bodies and missing lengths get a JSON-RPC parse error, and the server reads the next message.
* **Exact formatting edits**: `textDocument/formatting` ends its range at the true end of the document in UTF-16 units, so applying it no longer leaves a duplicate blank line.
* **The workspace cannot choose the binary**: the VS Code extension ignores `noyalib.path` in untrusted workspaces, refuses relative paths, and starts the server in the home directory.
* **In lockstep with noyalib 0.0.55**: the exact core pin moves to `=0.0.55`, so this release picks up every core change for that version, including limits enforced on every loader and linear-time parsing of long lines.
