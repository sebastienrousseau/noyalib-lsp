# noyalib-lsp 0.0.52

Hand-written Highlights for the GitHub release page; the rest of the page
(What's Changed, Checksums, Full Changelog) is generated at release time.

## Highlights ⭐️

* **Lockstep with noyalib 0.0.52**: Crate version, exact `=0.0.52` core pin, CITATION, README and policy snippets all read 0.0.52.
* **Source-aware diagnostics**: Stable `noyalib::*` diagnostic codes, ranges derived from the core structured diagnostic payload, UTF-8 byte spans converted to the UTF-16 line and character coordinates LSP 3.17 requires, and stale or partial spans clamped without splitting a scalar value. Regression coverage for source lines, emoji, malformed UTF-8 boundaries and codes.
* **VS Code extension metadata**: The extension manifest and its lockfile both read 0.0.52.
* **Registry pins finalised**: The pre-release git patch is gone from the root and fuzz manifests; both lockfiles resolve noyalib 0.0.52 from crates.io and cargo-vet records the registry crate.
